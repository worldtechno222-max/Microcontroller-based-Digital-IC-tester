# Microcontroller-based-Digital-IC-tester
Microcontroller-Based Digital IC Tester PCB designed using KiCad and Arduino Nano. This project can test common 14-pin  digital ICs using a DIP socket interface. The PCB includes status LEDs, buzzer indication, push-button controls, and LCD header support. 
# Microcontroller-based-Digital-IC-Tester PCB

A microcontroller-based digital IC tester PCB designed using KiCad and Arduino Nano.

## Features

- Arduino Nano based
- DIP-16 IC test socket
- Good/Bad LED indication
- Buzzer alert
- LCD interface
- Push button control

## Tools Used

- KiCad
- Arduino Nano
- Through-hole PCB design
